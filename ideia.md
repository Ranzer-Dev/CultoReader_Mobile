Instruções

Desenvolver um aplicativo mobile utilizando React Native com Expo e banco de dados SQLite, implementando um sistema completo de gerenciamento de dados (CRUD).

Organização
A atividade poderá ser realizada individualmente ou em duplas.
O tema do aplicativo é livre, permitindo criatividade na escolha do projeto.
A implementação deverá utilizar como referência a base de código disponibilizada no link do GitHub. https://github.com/Emerson-Rocha/SQLITE/tree/main/SQLITEMOBILE
Requisitos obrigatórios

O aplicativo deverá apresentar uma implementação funcional e completa das operações CRUD:

CREATE (Criar): cadastrar novos registros no banco de dados.
READ (Consultar): listar e visualizar os registros cadastrados.
UPDATE (Atualizar): editar registros existentes.
DELETE (Excluir): remover registros do banco de dados.
Funcionalidades exigidas
O projeto deverá obrigatoriamente conter:

Interface gráfica organizada e intuitiva.
Integração com banco de dados SQLite.
Formulário para cadastro de informações.
Listagem dos registros cadastrados.
Funcionalidade para editar registros.
Funcionalidade para excluir registros.
Cadastro e demonstração de pelo menos 10 registros.
Implementação de paginação na listagem dos registros, permitindo navegar entre as páginas.
Persistência dos dados, mantendo os registros mesmo após fechar e abrir o aplicativo novamente.
